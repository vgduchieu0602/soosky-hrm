# Project: Soosky HRM

## Overview

HRM Soosky is an enterprise-grade HRM platform built as a monolith split into two independently deployable applications:

- **Backend** — REST API powering all HR business logic
- **Frontend** — Web client for HR admins, managers, and employees

## Tech Stack

Frontend: React 19/Vite, TypeScript
Backend: Node.js, TypeScript
Database: MongoDB via Mongoose
Package Manager: pnpm
